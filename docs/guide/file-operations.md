# ファイル操作

マーク、削除、移動、複製などのファイル操作機能を説明する。

## マーク機能

「マーク」メニューの「マークを設定」「マークを解除」でファイルにマークを付け外しし、マークしたファイルへ一括操作を行う。
一括操作は同じメニューの「マークを完全に削除」（ごみ箱へ移す）、「マークを移動」、「マークを複製」、「マークをリストから削除」、「マークのファイル名をコピー」である。
マークした画像の間は「前のマーク画像へ」「次のマーク画像へ」で移動する。
キーの割り当ては各メニューの表示か[ナビゲーション](./navigation.md)を参照。

読み込み・展開前のアーカイブやPDFは、一覧に未展開コンテナとして表示される。
その項目へ移動すると背景での展開を待ち、完了後に中の画像やページへ切り替わる。

マーク一括の削除と移動は、表示中の項目の種別によらず実行でき、マークした通常ファイルだけを対象にする。
マークしたアーカイブ内画像・PDFページ・未展開コンテナは対象外であり、件数と理由をタイトルバーに表示する。
移動に成功したファイルは一覧から除かれ、マークも消える。キャンセルまたは失敗した場合は一覧を維持する。

複製は通常ファイルとアーカイブ内画像の内容を保存し、PDFページはPNGとして保存する。
アーカイブ内画像の保存名は`<アーカイブ名の拡張子を除いた部分>_<エントリのファイル名>`である（`photos.zip`内の`folder/sunset.png`は`photos_sunset.png`）。
PDFページの保存名は`<PDF名の拡張子を除いた部分>_page<1始まりのページ番号>.png`である（`report.pdf`の3ページ目は`report_page3.png`）。
未展開コンテナは複製の対象外であり、件数をタイトルバーに表示する。

## 単一ファイル操作

- 「ファイル」メニューの「リストから削除」: 表示中のファイルをリストから除く（ファイル自体は残る）
- 「ファイル」メニューの「ファイルを削除」（ごみ箱へ移す）、「ファイルを移動」、「ファイルを複製」
- 「画像」メニューの「ファイル名をコピー」「画像をコピー」: クリップボードへコピーする
- 「画像」メニューの「クリップボードから貼り付け」
- 「画像」メニューの「JPGとして保存」「BMPとして保存」「PNGとして保存」

単体の削除・移動も通常ファイルだけに適用する。移動に成功した行は一覧とマークから除かれる。
単体の複製は、[マーク機能](#マーク機能)で説明したマーク一括の複製と同じ内容と保存名を使う。

貼り付けた画像は、貼り付けごとに一時フォルダの別ファイルへ保存して開く。
別のウィンドウでの貼り付けや、後から貼り付けた画像に置き換わることはない。
一時ファイルは、貼り付けたウィンドウを閉じるときに削除する。

削除・移動・複製・保存・貼り付けなどの操作に失敗した場合は、原因をタイトルバーに表示する。
表示は次の操作を始めるまで残る。キャンセルした操作は失敗として表示しない。

## ファイルリスト管理

### ソート

数値を認識する自然順ソート（デフォルト）、ファイル名順、大文字・小文字の区別なし、
ファイルサイズ順、最終更新の日時順に対応している。

### シャッフル

ファイルリスト全体のシャッフル、フォルダの並び順のシャッフルができる。

### ブックマーク

現在のファイルリストと表示位置を独自テキスト形式 (`.gvbm`) で保存・復元できる。
