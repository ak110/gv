# カスタマイズ

設定ファイルとキーバインドのカスタマイズ方法を説明する。

## 設定ファイル

`ぐらびゅ.toml`をexeと同じディレクトリに配置することで設定をカスタマイズできる。
同梱の`ぐらびゅ.default.toml`をコピーしてリネーム。

## キーバインド

`ぐらびゅ.keys.toml`をexeと同じディレクトリに配置することで、ほぼ全ての操作のキーバインドをカスタマイズできる。
同梱の`ぐらびゅ.keys.default.toml`をコピーしてリネームし、編集。
変更する操作だけを記載してもよい。
記載した操作の割り当ては全て置き換わり、省略した操作はデフォルトの割り当てを使う。
空文字列を指定すると、その操作の割り当てを解除する。
ユーザー設定のキーが別の操作のデフォルトと重なる場合は、ユーザー設定を優先する。
メニューには最初のキー、ヘルプには割り当てた全てのキーを表示する。
TOMLの構文やキーの指定が不正な場合はstderrに原因を出力し、デフォルトの割り当てを使う。
設定ファイルが無い場合や読み取れない場合も、デフォルトの割り当てを使う。

### TOML構造の例

```toml
# ぐらびゅ.keys.toml
# 複数キーの割り当て: カンマ区切り (例: "Ctrl+Num -, Ctrl+WheelUp")

[file]
new_window = "Ctrl+N"
open_file = "Ctrl+O"
open_folder = "Ctrl+Shift+O"
close_all = "Ctrl+W"

[mark]
set = "Delete"
unset = "Ctrl+Delete"
invert_all = "Ctrl+Shift+I"
# ... 以下同様
```

### キー名の記法

| 記法                                    | キー                    |
| --------------------------------------- | ----------------------- |
| `←` `→` `↑` `↓`                         | 矢印キー                |
| `PageUp` `PageDown`                     | ページアップ/ダウン     |
| `Home` `End`                            | Home / End              |
| `Enter` `Space` `Tab` `Esc` `BackSpace` | 各種キー                |
| `Delete`                                | Delete                  |
| `F1` 〜 `F12`                           | ファンクションキー      |
| `Num0` 〜 `Num9`                        | テンキー数字            |
| `Num +` `Num -` `Num *` `Num /`         | テンキー演算子          |
| `Ctrl+` `Shift+` `Alt+`                 | 修飾キー (組み合わせ可) |
