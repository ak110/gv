# 画像編集

矩形選択、トリミング、回転、フィルタなどの画像編集機能を説明する。

## 矩形選択

マウスドラッグで矩形領域を選択できる。
選択範囲は8方向リサイズハンドルでサイズ変更、ドラッグ移動が可能である。
選択は「画像」メニューの「選択範囲を取り消し」で解除する。

## トリミング・回転・リサイズ

- 「画像」メニューの「画像のトリミング」: 選択範囲の外側を除いた画像にする
- 「編集」メニューの「左右反転」「上下反転」「180度回転」「時計回りに90度回転」「反時計回りに90度回転」「角度指定回転」（任意角度はバイリニア補間）
- 「編集」メニューの「解像度の変更」: Lanczos3リサンプリングでリサイズする

## フィルタ

フィルタは「画像」メニューの各項目（「レベル補正」「ガウスぼかし」など）で適用する。
選択範囲がある場合は、その領域にのみフィルタを適用する。
パラメーターは入力欄に表示された範囲で指定する。
範囲外や数値でない入力ではダイアログを閉じず、該当する入力欄を選択する。値を修正して再度OKを押す。

- 色調補正: レベル補正、ガンマ補正、明るさとコントラスト、色の反転、グレースケール（簡易/厳密）
- ぼかし・シャープ: ガウスぼかし、ぼかし（通常/強い）、アンシャープマスク、シャープ（通常/強い）、メディアンフィルタ
- 効果: 塗り潰し、モザイク、α合成

## 永続フィルタ

画像のナビゲーション（切り替え）を行っても全画像に自動的に適用されるフィルタである。
起動時は無効なので、「フィルタ」メニューの「フィルタを有効にする」を選ぶ。
続けて同じメニューから適用する操作を選ぶ。追加した順序で適用する。
各操作はメニューの同じ項目をもう一度選ぶと外れる。
