# はじめに

## インストール

[Releases](https://github.com/ak110/gv/releases)からZIPをダウンロードし、任意のフォルダに展開する。
展開したフォルダの`ぐらびゅ.exe`を起動する。

## 基本的な使い方

「ファイル」メニューの「ファイルを開く」「フォルダを開く」か、ウィンドウへのドラッグ&ドロップで画像ファイル・フォルダを開ける。
アーカイブ（ZIP・RAR・7zなど）とPDFも同じ操作で開ける。
シェル統合を登録すると、エクスプローラーのファイル関連付けや「送る」からも開ける。
コマンドラインから `ぐらびゅ.exe image.jpg` のように指定して起動できる。

画像ファイルを開くと、同一フォルダ直下の画像ファイルを自動的にリストに追加する（サブフォルダは対象外）。
フォルダを開くと、サブフォルダ内の画像・PDF・アーカイブまで再帰的に取り込む。
親フォルダから順にサブフォルダの内容を続けて並べる。
アーカイブファイルを開くと、内部の画像をリストに追加する。
ZIP（`.zip`・`.cbz`）の画像は展開せず、アーカイブから直接読み込む。
RAR・7z・Susieプラグインのアーカイブは、一時フォルダへ展開して読み込む。

## コマンドライン引数

| 引数           | 動作                                                       |
| -------------- | ---------------------------------------------------------- |
| ファイルパス   | 指定した画像ファイルやフォルダを開く                       |
| `--register`   | ファイル関連付け・コンテキストメニュー・「送る」を一括登録 |
| `--unregister` | 一括解除                                                   |

`--register`・`--unregister`はコマンドプロンプトで展開したフォルダへ移動し、`ぐらびゅ.exe --register`のように実行する。
画面からは「ヘルプ」メニューの「シェル統合を登録...」「シェル統合を解除...」で同じ登録・解除ができる。
