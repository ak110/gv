# 画像の表示

表示モード、ズーム、スライドショーなどの表示機能を説明する。

## 表示モード

- 自動縮小表示: ウィンドウサイズに収まるよう画像を縮小
- 自動縮小・自動拡大表示: ウィンドウサイズに合わせて縮小・拡大する（デフォルト）
- 倍率の拡大（×1.4）/ 縮小（×0.7）/ リセット (×1.0)

操作による自動表示の切り替えは、自動縮小と自動縮小・自動拡大の2種類である。
自動拡大のみ、原寸大、固定倍率は、設定ファイルの`[display]`の`auto_scale`で選ぶ。

## 写真の向き

JPEG・PNG・WebPなどが持つEXIFの向き情報（回転・左右反転）に従って、撮影時の向きで表示する。
選択範囲・トリミング・保存・クリップボードコピーも表示と同じ向きで扱う。
元のファイルは変更しない。
PDFのページとSusieプラグインで読み込んだ画像は、向き情報による補正の対象外である。

## 余白・αチャネル

- 画像とウィンドウ端の余白量を設定可能（トグル）
- PNG等の透過画像に対して背景色を切り替え可能（白、黒、チェッカーパターン）

## 画像情報

- 画像サイズ（幅×高さ）、ファイルサイズ、ファイルパスをタイトルバーと画像情報ダイアログで表示
- JPEG等のEXIF情報（カメラ、レンズ、焦点距離、F値、シャッター速度、ISO感度、撮影日時、GPS座標）を画像情報ダイアログに表示

## スライドショー

スライドショーの開始/停止、加速、減速の操作で自動送りを調整する（500ms〜30秒）。
デフォルトのキーは[ナビゲーション](./navigation.md)を参照。
最後の画像に到達すると最初に戻る（設定で無効化可能）。
手動でナビゲーションを行うと自動的に停止する。フルスクリーンモードと併用できる。

デフォルトの間隔やリピート設定は設定ファイルの`[slideshow]`セクションで変更できる
（設定ファイルの詳細は[カスタマイズ](./customization.md)を参照）。

## ピクセルグリッド表示

高倍率ズーム時にピクセル境界をグリッド線で表示する。
