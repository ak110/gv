# ナビゲーション

キーボードとマウスによる画像間の移動操作を説明する。

## デフォルトの割り当て

| キー              | 操作                      |
| ----------------- | ------------------------- |
| ← / →             | 前後の画像に移動          |
| ↑ / ↓             | 前後の画像に移動          |
| ホイール上/下     | 前後の画像に移動          |
| PageUp / PageDown | 5件前 / 5件後へ移動       |
| Ctrl+PageUp/Down  | 50件前 / 50件後へ移動     |
| Ctrl+Home / End   | 最初 / 最後へ             |
| Ctrl+ホイール上   | 倍率を0.7倍する           |
| Ctrl+ホイール下   | 倍率を1.4倍する           |
| 左ダブルクリック  | ウィンドウ最大化トグル    |
| ホイールクリック  | 画像情報表示              |
| Num /             | 自動縮小表示              |
| Num \*            | 自動縮小・拡大表示        |
| Num 0             | 余白の表示/非表示         |
| A                 | 透過部分の背景を切替      |
| Alt+Enter         | フルスクリーン            |
| Esc               | メニューバー表示/非表示   |
| F4                | ファイルリスト表示/非表示 |
| Shift+Space       | スライドショー開始/停止   |
| Shift+↑           | スライドショー加速        |
| Shift+↓           | スライドショー減速        |

件はファイルリストの項目を数える。
余白量は設定ファイルの`[display]`の`margin`で変える。
透過部分の背景は白、黒、チェッカーパターンの順に切り替わる。

全キーバインドの一覧は`ぐらびゅ.keys.default.toml`を参照。
キーバインドのカスタマイズ方法は[カスタマイズ](./customization.md)を参照。
